# OpenSpec Archive with GitHub
Always use the GitHub Project "Drone Inventory Project" of owner JuuSte.

## Workflow
1. Check that all tasks in tasks.md are ticked and all related issues are closed/merged.
   If not, stop and list what is missing.
2. Set all related issues to "Done" in the project and add a comment with the OpenSpec change reference.
3. Archive the change with opsx:archive.
